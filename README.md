# School Kanban

A simple kanban board designed for students to organize and track their tasks and assignments.

## Features

- Create, edit, and delete tasks
- Organize tasks into columns (e.g., To Do, In Progress, Done)
- Drag and drop tasks between columns
- Simple and intuitive interface

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/olakunleolatunji/school-kanban.git
   ```

2. Navigate to the project directory:
   ```bash
   cd school-kanban
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npm start
   ```

## Usage

1. Add tasks to the "To Do" column
2. Move tasks to "In Progress" when you start working on them
3. Move completed tasks to "Done"
